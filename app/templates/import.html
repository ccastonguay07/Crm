Import Contacts

Upload a CSV file from Google Contacts or LinkedIn. Column names are detected automatically.

Supported export formats

Google Contacts

  1. Open contacts.google.com
  2. Click the export icon (top-right) → Export as Google CSV
  3. Upload the downloaded file here

LinkedIn Connections

  1. Go to LinkedIn → Settings → Data Privacy → Get a copy of your data
  2. Request Connections export → download the zip
  3. Upload Connections.csv from the zip here

Generic CSV

Any CSV with a Name or Full Name column. Optional columns: Email, Phone, Company, Job Title, Tags (comma/semicolon-separated), Notes.
